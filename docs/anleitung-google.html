Google Workspace einrichten

Diese Anleitung ist für die Person, die euer Google Workspace verwaltet. Sie legt einmal ein Dienstkonto an, über das das Display Kalender und Google Tasks liest. Dauer: etwa 15 Minuten. Es entstehen keine Kosten.

Am Ende brauchst du für das Display: die Schlüsseldatei (JSON) des Dienstkontos und die E-Mail-Adresse der Person, deren Kalender angezeigt werden.

Wichtig: Die Schlüsseldatei ist ein Zugang. Nicht per Mail verschicken, nach dem Hochladen auf das Display löschen.

In der Google Cloud Console

  1. Projekt wählen oder anlegen
    console.cloud.google.com öffnen und oben ein Projekt wählen oder Neues Projekt anlegen.
  2. Schnittstellen einschalten
    APIs und Dienste, Bibliothek: Google Calendar API aktivieren, dann Google Tasks API aktivieren.
  3. Dienstkonto anlegen
    IAM und Verwaltung, Dienstkonten, Dienstkonto erstellen. Name: TRMNL Display. Rollen und Nutzer überspringen, Fertig.
  4. Schlüssel erzeugen
    Das neue Dienstkonto öffnen, Schlüssel, Schlüssel hinzufügen, Neuen Schlüssel erstellen, Typ JSON. Die Datei wird heruntergeladen.

    Kommt die Meldung, dass das Erstellen von Schlüsseln gesperrt ist: Das ist eine Richtlinie der Organisation (iam.disableServiceAccountKeyCreation). Ein Organisationsadministrator kann sie für dieses Projekt aufheben.

  5. Client-ID notieren
    Im Dienstkonto unter Details die eindeutige ID (eine lange Zahl) kopieren.

In der Google Admin-Konsole

  1. Domainweite Delegierung
    admin.google.com: Sicherheit, Zugriffs- und Datenkontrolle, API-Steuerung, Domainweite Delegierung, Neu hinzufügen.
  2. Zugriff festlegen
    Client-ID: die lange Zahl von eben. OAuth-Bereiche, beide in eine Zeile: 
    https://www.googleapis.com/auth/calendar.readonly,https://www.googleapis.com/auth/tasks.readonly
    Dann Autorisieren.

    Damit darf das Dienstkonto Kalender und Aufgaben nur lesen. Bis die Freigabe wirkt, können einige Minuten vergehen.

Am Display

  1. Einrichtung öffnen
    Am Display die Taste 2 Sekunden halten und den QR-Code scannen.

    Die Schlüsseldatei lässt sich am einfachsten vom Computer aus hochladen: im WLAN-Menü des Computers das WLAN „TRMNL-…“ wählen (Passwort steht auf dem Display) und im Browser 192.168.4.1 öffnen.

  2. Google verbinden
    Kalender und Aufgaben, bei Google Workspace auf Verbinden, die Schlüsseldatei wählen und die E-Mail-Adresse eintragen.
  3. Kalender auswählen
    Die Kalender einschalten, die erscheinen sollen. Fertig.
